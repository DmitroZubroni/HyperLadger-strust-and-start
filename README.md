# Hyperledger Fabric: решения конкурсных заданий

Сеть поднимается официальным `test-network`. Запуск в Ubuntu: на компьютере, в виртуальной машине или в WSL.

| Папка | Что это | Интерфейс |
| --- | --- | --- |
| `basic-js` | Базовое задание на JavaScript | http://localhost:3005 |
| `2025_B1` | Модуль Б, черновик на старой схеме, целиком не проверен | |

Установка и запуск описаны в `INSTRUCTION.md` внутри каждой папки решения.
