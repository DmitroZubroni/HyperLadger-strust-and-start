# Hyperledger Fabric: решения конкурсных заданий

Hyperledger Fabric 2.5, локальная сеть поднимается официальным `test-network`, контракт вызывается через Fabric Gateway. Запуск в Ubuntu: на компьютере, в виртуальной машине или в WSL.

| Папка | Что это | Интерфейс |
| --- | --- | --- |
| `basic-js` | Базовое задание на JavaScript | http://localhost:3005 |
| `basic-java` | Базовое задание на Java, не развивается, чата в этой версии нет | http://localhost:3006 |
| `2025_B1` | Модуль Б «Безопасное дорожное движение»: организации Bank и Users, канал blockchain2025 | http://localhost:3005 |

Пошаговая разработка решения на Fabric на JavaScript: [GUIDE.md](GUIDE.md).

Схема организаций, пользователей и взаимодействия компонентов описана в [ARCHITECTURE.md](ARCHITECTURE.md).

Команды для работы с самим Fabric (состояние ноды, пользователи и сертификаты, организации) собраны в [COMMANDS.md](COMMANDS.md).

Установка и запуск описаны в `INSTRUCTION.md` внутри каждой папки решения. Решения запускаются по очереди: они используют одну сеть и порт 8091.
