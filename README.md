# Hyperledger Fabric: решения конкурсных заданий

Запуск в Linux, в виртуальной машине или в WSL с Ubuntu. Нужны Docker и Node.js 18+.

| Папка | Что это | Запуск | Интерфейс |
| --- | --- | --- | --- |
| `basic-js` | Базовое задание, контракт и API на JavaScript | `./Start` | http://localhost:3005 |
| `basic-java` | Базовое задание, контракт и API на Java | `./Start` | http://localhost:3006 |
| `2025_B1` | Модуль Б, черновик: ещё не переведён на схему с Microfab и не проверен целиком | | |

В каждой папке базового задания есть своя инструкция `INSTRUCTION.md`. Решения запускаются по очереди: они используют один контейнер и порт 8090.
